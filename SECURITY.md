# Security policy

## Supported versions

Security fixes are made on the latest published release line. Upgrade to the
latest release before reporting behavior which is already corrected there.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
[private vulnerability reporting form](https://github.com/ajyadav013/asyncio-gateway/security/advisories/new)
and include:

- the affected asyncio-gateway and Python versions;
- the protocol and configuration involved;
- a minimal reproducer or clear reproduction steps;
- the expected impact and any known workaround.

Avoid including live credentials, private keys, customer data, or production
hostnames. The maintainer will acknowledge a complete report within seven days
and coordinate disclosure after a fix is available.
